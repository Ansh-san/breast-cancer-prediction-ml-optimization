For this project, I developed a supervised machine learning model to predict whether a breast mass is malignant or benign using the Wisconsin Diagnostic Breast Cancer dataset. The dataset contains 569 samples and 30 numerical features derived from cell-nucleus images. I selected a support vector machine because it handles continuous features and can represent both linear and nonlinear decision boundaries. Since malignant cases are the positive class, I reversed the dataset's original target encoding and focused on metrics that measure how accurately those cases are identified.

I split the data into stratified training and test sets using an 80:20 ratio. To prevent data leakage, I placed feature standardization and the classifier in a pipeline, so the scaler was fitted only on the training portion of each validation fold. I compared a default model against 50 hyperparameter combinations using stratified five-fold cross-validation and malignant F1 as the selection metric. The best model used a radial basis function kernel, C=10, gamma=0.01 and balanced class weights.

On the held-out test set, the model achieved 99.12% accuracy, 100.00% malignant precision, 97.62% malignant recall and 98.80% malignant F1. The confusion matrix contained one false negative and no false positives among 114 test cases. I also generated a receiver operating characteristic curve, a confusion matrix and a cross-validation comparison plot.

The report explains the algorithm choice, preprocessing, training procedure, hyperparameter tuning, evaluation methods, challenges and limitations. It emphasizes that results from a small historical dataset and a single test split do not establish clinical reliability. The Python code is reproducible, uses a publicly available built-in dataset and includes comments explaining each stage. The model is intended for educational purposes only and must not be used for diagnosis.
